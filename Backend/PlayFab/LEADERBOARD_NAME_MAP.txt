Prefix meanings
---------------
CC_E_ = Efficient leaderboard
        Lowest bridge cost ranks first; lower peak stress breaks a tie.

CC_S_ = Strongest leaderboard
        Lowest peak stress ranks first; lower bridge cost breaks a tie.

PlayFab uses Maximum aggregation because the game converts a better, lower
cost/stress result into a larger encoded integer. The values shown by PlayFab
are encoded ranking values, not the raw cost or stress.

----------------------------------------------------

Source of truth
---------------
Unity creates these names in:
Assets/Script/UI/Leaderboards/LeaderboardScoreCodec.cs

The server allowlist is in:
Backend/PlayFab/leaderboardCloudScript.js

When a new playable contract is added, add its contract ID and hash to the
server allowlist, create both CC_E_ and CC_S_ PlayFab statistics, and update
this file.
