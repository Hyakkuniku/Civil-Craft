# Compact tutorial instruction display

Run `dotnet run --project Tests/TutorialInstructionCopy` from the Unity project.

Directly compiles the pure production `TutorialInstructionText` helper. Independent fixtures cover the existing Beam/Truss tool instructions and feedback, both Erase/Move introductions, Almanac and Shop walkthroughs, and first bridge results. Checks require visibly shorter verbose stock copy without losing its core actions/concepts, unchanged already-short Erase/Move introductions, balanced TMP emphasis, idempotence, and exact pass-through for unknown/custom/empty text. Positioning a copied preview remains distinct from the following explicit Paste confirmation step.

Source guards require compact text assignment before native layout/animation, unchanged authored action callbacks and button gates, and native previews using the same display copy. Calling the formatter is verified not to write either scene or the original build-authoring source. This is a text/integration test, not a native font/layout or gameplay-input simulation. Existing Beam/Truss action and pointer suites continue to verify those behaviors separately.
