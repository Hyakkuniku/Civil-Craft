Run from the Unity project root:

```powershell
dotnet run --project Tests/MarshUnlock/MarshUnlock.csproj
```

Use `-- --source-only` before the scene update is saved. The suite executes the production spawn-condition class and independent monitor directly against controlled data, including missing player data, neither/one/both contract completions, inactive-NPC activation, reload, profile changes, and marker readiness. The frozen baseline protects existing Marsh/Silas phases, dialogue, lessons, quizzes and all six related contracts. Saved-scene checks require Marsh's existing root to start inactive with exactly the two Silas main-contract prerequisites. No scene or player data is modified by these tests.
