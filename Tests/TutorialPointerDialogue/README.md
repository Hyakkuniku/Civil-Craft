Run from the Unity project root:

```powershell
dotnet run --project Tests/TutorialPointerDialogue/TutorialPointerDialogue.csproj
```

The test executes the production TutorialPointer request, hide, visibility, enable and LateUpdate methods and its actual suppression property. Geometry placement, Unity objects, rendering and modal/dialogue providers are boundary doubles. It checks visible dialogue and closing animation, repeated and replaced targets, owner cancellation, temporarily inactive targets, build geometry ownership, modal priority, canvas-free masking, authored opacity and inactive parents.

The test does not open live scenes, invoke game callbacks, modify player data or contact the network.
