# Almanac CLOSE / tutorial SKIP slot

Run `dotnet run --project Tests/AlmanacTutorialSkipSlot/AlmanacTutorialSkipSlot.csproj`.

Compiles the production placement/state helper and extracts the actual TutorialManager
ownership gate. Checks screen-size matching across Canvas scales, parent-pivot offsets,
moving book controls, exact CLOSE alpha/input restoration, returning global SKIP layout,
multiple owners, rejected projections/cameras, hidden or unusable SKIP, book ownership,
top-panel priority, and lifecycle cleanup. RectTransform projection, Canvas objects,
and Almanac owner readiness are explicit engine/integration doubles. Real rendering,
touch hit-testing, and hold-to-skip behavior still require Unity/device checks.
